Week 4: Replicating week 2's visitor counter

Welcome to my fourth linux project! This site is running on a clone server of the week 2 setup.

In this project, I have replicated the visitor counter from week 2. This site does not increment the counter, but simply mirrors the counter value from week 2's site

There have been {{ result }} visitors on week 2 page

The visitor counter is stored in a MySQL database. Whenever the week 2 page is visited or refreshed, the Flask application updates the counter by executing SQL queries and displays the current total. Counter values are synchronized between the two sites, but only the week 2 site increments the counter.
