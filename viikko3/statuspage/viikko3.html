For this project I used following commands:

  • date '+%d.%m.%Y %H:%M %Z' : To get the current date, time and timezone
  • uptime -p : To get the uptime of the server in "pretty" format
  • free -h | awk '/Mem:/ {print "Used: " $3 " | Available: " $7 " | Total: " $2}' : To get the used, available and total memory. Pipe them to awk which reads info from the line with memory information
  • free | awk '/Mem:/ {printf "%.0f", $3/$2*100}' : Use free with piping to awk to get the percentage of used memory
  • df --output=pcent / | tail -1 | tr -dc '0-9' : To get the percentage of used disk space on root filesystem, select only the last line and remove all non-numeric characters

How the script works?

This script generates a status page in HTML format that displays the server's current status, including the date, time, timezone, uptime, memory usage, disk usage and disk health. It collects server information using Linux commands and stores the results in Bash variables through command substitution.

There is also a function that checks if the disk usage exceeds a certain threshold (80%) and displays a warning message if it does. Otherwise, it shows that the disk usage is OK.

Disk space warning logic is implemented in the disk_status function. It checks the disk usage percentage and sets the DISK_HEALTH variable accordingly. Check how its done from my GitHub page.

How the script is scheduled to run?

Script is timed to run every minute using a cron job, ensuring that the status page is always up-to-date.

To schedule the script to run every minute, I added the following line to the crontab file:

* * * * * sudo ./projects/linux_course/viikko3/status.sh
